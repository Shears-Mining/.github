# Shears Mining – keeping small SHA-256 coins alive

We run a solo and merge-mining pool for Bitaxe and home miners, and we look after the **open-source code of the small SHA-256 coins** we mine.

**What you'll find here**

- 🗄️ **Preserved coins** – every coin we mine is forked here first, so its source, history and releases can't disappear when its developers move on.
- 🛡️ **[Shears StallGuard](https://github.com/Shears-Mining/stallguard)** – ASERT difficulty with a stall rescue and a floor, so a big miner leaving can't freeze a small chain. Free to use (MIT).
- ⛓️ **Merge-mining (AuxPoW) upgrades** – letting Bitcoin miners secure small coins at no extra cost.
- 🔧 **Community releases** for abandoned coins – tested on private test chains, with Windows, Linux and Raspberry Pi wallets, full source, checksums, and credit to the original developers.
- 🔍 **Infrastructure** – public nodes and [block explorers](https://sha256-mining.shears.co.uk/explorers.php) for coins that have lost theirs.
